# Sonic 4C — Bônus Oficial para Compradores do Sistema 4C

Obrigado por adquirir o **Sistema 4C**!

Como material extra, disponibilizo este suplemento especial inspirado em um universo de velocidade, ação constante e aventuras cheias de personalidade.

## Sobre este bônus

**Sonic 4C** é uma adaptação temática do Sistema 4C voltada para campanhas dinâmicas, cenários tecnológicos e personagens marcantes.

Neste arquivo você encontrará:

- Novos poderes focados em velocidade e ação;
- Tecnologia substituindo magia através do sistema **Hi-Tech**;
- Regras de **Engenhocas**;
- Grupos narrativos para criação de personagens;
- Fichas prontas de heróis, vilões e inimigos;
- Inspiração para aventuras rápidas e eletrizantes.

## Conteúdo

- Mobianos, Humanos, Bots e Badnikborns;
- Personagens clássicos adaptados;
- Inimigos prontos para usar;
- Regras simples e compatíveis com o livro base.

## Como usar

Você pode utilizar este suplemento de três formas:

1. Como cenário próprio;
2. Como crossover com campanhas normais do 4C;
3. Como referência para criar aventuras velozes em qualquer mundo.
